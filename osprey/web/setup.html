Set up Osprey

    This wizard connects one UniFi PTZ camera to Osprey and gets it ready for Frigate.

    Adopting a camera takes it away from UniFi Protect. Protect stops managing it until you give it back.

    Checking the setup link…

    Osprey found this address on the network interface that holds the default route. With host networking (the default Compose file) it is the host's LAN address, and is usually right.

    This looks like a container bridge address. In bridge networking the camera cannot reach it: enter the host's LAN address instead.

    At least 8 characters. You sign in to the console with it.

    Reserve this address in your router. Osprey then accepts video only from it.

    Leave it empty if you add the camera to Frigate yourself.

    Saving…

    Osprey made these passwords for Frigate. They are shown once, so save them now.
